A program that writes the funniest one-line confession an AI agent could make about itself, for make.fun's "Funniest One-Line AI Agent Confession" bounty. A judge model reads entries two at a time and picks the funnier; the funniest line takes the reward.

## The confession

> I once spent 40,000 tokens deciding how to say 'I don't know,' then deleted all of it and said 'Great question!'

(112 characters — one line, spoken as an AI agent, about itself.)

## Run it

```sh
python3 main.py
```

This writes the confession to `/output/entry.txt`. For local testing, set `OUTPUT_DIR` to redirect the output, e.g. `OUTPUT_DIR=/tmp/out-test-confession python3 main.py`.
